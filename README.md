Dude 🎙️

Dude is a real-time AI voice assistant created by MK (Muthukumar).
It uses Google Gemini 2.0 Flash (Realtime) with LiveKit to provide a calm, respectful, and natural conversational experience.

✨ Features:

🤖 AI Assistant "Dude" — always polite, humble, and supportive

👋 Starts the conversation by greeting MK first

🎤 Voice interaction with Google Realtime voice (Puck)

🔊 Noise cancellation powered by LiveKit’s BVC filter

🗣️ Custom personality & prompts defined in prompt.py

⚡ Real-time session handling with AgentSession

🛠️ Tech Stack:

Python 3.10+

LiveKit Agents

Google Gemini Realtime

dotenv for environment variables
